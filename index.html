Run your own teaching platform.

Mathion hosts your courses, assignments, and student work on a server you control — installed and kept up to date from the terminal, with releases you can cryptographically verify.

What it is

Your platform, on your server.

  • Yours to hostRuns on your own machine with Docker. Your students and their data stay with you.
  • One commandThe mathion CLI installs, backs up, restores, and updates the whole stack.
  • VerifiableEvery release is GPG-signed; the installer checks the signature before it installs anything.

Install

Two ways to install.

The one-liner above downloads the latest release, verifies its signature and checksum, and installs mathion to /usr/local/bin. Prefer to read before you run:

inspect, then run 
curl -fsSL https://raw.githubusercontent.com/svkucheryavski/mathion/main/deploy/install.sh -o install.sh
less install.sh          # review what it does
sudo sh install.sh

On Debian/Ubuntu you can instead add the apt repository, so mathion upgrades with the rest of the system. The first keyring fetch is trust-on-first-use — verify its fingerprint before relying on it.

apt setup 
sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://svkucheryavski.github.io/mathion/deb/mathion-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/mathion-archive-keyring.gpg >/dev/null
sudo chmod 0644 /usr/share/keyrings/mathion-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/mathion-archive-keyring.gpg] \
  https://svkucheryavski.github.io/mathion/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/mathion.list
sudo apt update && sudo apt install mathion

Trust

Verify the release key.

Mathion's releases are signed by an offline key. Because the first keyring you receive is trusted as-is, confirm it against the fingerprint published here — an independent source from the download itself — before you rely on it. They must match exactly.

Primary key fingerprint

F006 02DF E1BF 8CD2 B321  FC72 AD21 D4AD 294C 31A0
check it 
gpg --show-keys /usr/share/keyrings/mathion-archive-keyring.gpg

If the fingerprint printed by that command doesn't match the one above, stop — do not trust the keyring. The fingerprint is also recorded in the repository, but that copy shares an origin with the download, so this page (and any other channel you trust) is the independent check.
